# 🎓 Campus Connect

A web-based **College Management System** developed using **Python (Flask)** that simplifies communication and academic management for students, faculty, and administrators.

---

## 📌 Project Overview

Campus Connect is an academic project that provides a centralized platform for managing various college activities. It enables students, faculty members, and administrators to perform their respective tasks through an easy-to-use web interface.

---

## ✨ Features

### 👨‍🎓 Student Module
- Student Registration & Login
- Student Dashboard
- Attendance Management
- View Announcements
- View Events
- Profile Management
- Resume Builder
- Resource Access
- Feedback Submission

### 👨‍🏫 Faculty Module
- Faculty Dashboard
- Attendance Management
- Create Events
- View Student Resumes
- Upload Learning Resources
- Manage Announcements

### 👨‍💼 Admin Module
- Admin Dashboard
- Manage Students
- Manage Faculty
- Create Announcements
- Manage Events

## 🚀 Installation & Running the Project

1. Clone this repository.

```
git clone https://github.com/gosavivaibhavi2006-beep/Campus-Connect.git
```

2. Navigate to the project folder.

```
cd Campus-Connect
```

3. Install Flask.

```
pip install flask
```

4. Run the application.

```
python app.py
```

5. Open the application in your web browser.
